This project is a REST API built using Python and FastAPI for my DS 3500 class. The API allows users to upload CSV files, store datasets, and retrieve data using different endpoints. It also connects to my MP1 data pipeline to validate and process datasets by removing duplicates, handling missing values, and detecting outliers. The project uses Pandas for working with data, Pydantic for validating requests, and middleware to log API requests and responses. I also used pytest to test the endpoints and make sure uploading, processing, and retrieving datasets work correctly.
